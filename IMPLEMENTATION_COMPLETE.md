## 🚀 How to Use

### Quick Start (1 minute):
```bash
./start.sh
# Opens web interface at http://localhost:5000
```

### Demo (see it in action):
```bash
python demo.py
# Generates sample bids, shows all features
```

### Command Line:
```bash
python cli.py --project "Steel Gate" --images photo.jpg
```

### Python:
```python

manager = JobBidManager()
result = manager.generate_complete_bid(

)
```
